# Changelog

## 2026-09 — first release

- `setup.sh` for Ubuntu, Debian, RHEL, Rocky, AlmaLinux and Fedora (x86_64 and
  aarch64): distro packages, Oh My Posh, eza, ble.sh, the kali theme, the
  profile and a `~/.bashrc` hook. Dry run, diagnose, update and uninstall modes.
- `darthshell.bash`: the Bash version of the PowerShell profile — prompt,
  predictions and highlighting, DarthAdmin colours, history hygiene, fzf,
  cached tab completion for kubectl/helm/gh/oh-my-posh/dotnet, Microsoft 365,
  server and WSL helpers, and the PowerShell command names as aliases.
- ShellCheck and a multi-distro install test on every push.
